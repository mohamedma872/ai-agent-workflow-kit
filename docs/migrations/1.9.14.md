# Migration to 1.9.14

No action required. Existing projects keep the workflow's own executors until they opt in.

## Choosing the executor per project

Add to `.agentic/config.yaml`:

```yaml
executors:
  default: claude          # every role
  roles:                   # optional, overrides default per role
    implementation: codex
```

`agentic init` writes the block commented out, so a new project sees the option without it taking effect.

Check what a role will actually use:

```bash
agentic doctor            # confirms both CLIs are present
node ai/workflow/router.js resolve feature implementation
# feature/implementation → claude (fallbacks: codex)
```

## When you would set it

`implementation` and `fixes` default to codex. Point them at claude when codex is unavailable — out of credit, or unable to run your toolchain. Flutter is the current example: codex runs with `--sandbox workspace-write` and Flutter writes its SDK cache outside the workspace, so every `flutter` command fails for it.

Remove the block to go back to the workflow defaults.
