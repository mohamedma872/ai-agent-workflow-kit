# Migration to 1.8.0

No action required. Workflow, artifact and state formats are unchanged; `state.json` only gains optional fields on runs you close.

## Closing from the dashboard

`c` closes the highlighted feature after a confirmation:

```text
 Close FEAT-002 at 43% — verification has not passed, so it is recorded as
 abandoned.  y = confirm · any other key = cancel
```

| Run | Result |
|---|---|
| verification passed | closed, as `runs.js close` always did |
| verification not passed | closed and marked `abandoned: true` with a `closedReason` and an `abandon` entry in the run history |

The verification gate did not move. `node ai/tasks/feature/runs.js close <id>` still refuses an unverified run unless `AI_WORKFLOW_ADMIN=1`, there is no `--force`, and the dashboard supplies admin mode only for a confirmed keypress on a real terminal.

## Reading closed runs

```bash
agentic runs --all
```

Abandoned runs now show `abandoned` in the STATE column instead of `done`. Anything parsing `agentic runs --json` sees a new `abandoned` boolean per run.

## Fixed

`runs.js close FEAT-TYPO` used to create `FEAT-TYPO/state.json` and report it closed. It now fails with `unknown run FEAT-TYPO`.
