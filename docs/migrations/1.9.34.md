# 1.9.34 — Notification click, device-check safeguards, base repair

Runtime 1.9.34 changes `ai/workflow/notify.js`, `ai/tasks/feature/mobile-evidence.js`, `ai/workflow/worktree.js`, `ai/workflow/analyzer-baseline.js`, `ai/workflow/progress.js`, `ai/workflow/role-activity.js`, `ai/tasks/feature/runs.js` (`conditional … in_progress`), `ai/workflow/engine.js` and the doctor. Stages, gates, routing and artifact formats are unchanged.

## What changes for you

- **macOS:** run `brew install terminal-notifier`, and clicking a run's notification brings your terminal (or VS Code) forward instead of opening Script Editor. `agentic doctor` reminds you.
- **The device check** shows in `agentic progress` (`d`) and `agentic activity`. It no longer leaves `project.pbxproj` or `Runner.xcscheme` changes behind.
- **Runs from before 1.9.31** get their base repaired on the next resume. The old value is kept in `engine/worktree.json` under `baseRepaired`.
