# Migration to runtime 1.0.0

Version 1.0.0 is the first private **AI Agent Workflow Runtime** release. It evolves the earlier `ai-agent-workflow-kit` into a deterministic runtime.

For repositories copied from the older kit:

1. Replace the runtime control-plane files with the 1.0.0 versions rather than mixing old `runs.js`/router/guard files with the new engine.
2. Run `npm ci`, then `npm run workflow:version:check` and `npm run exam:check`.
3. Start new feature work through `npm run workflow:start -- <run-id> --request "..."`; the engine now owns stage progression.
4. Product implementation runs in `.ai-worktrees/<run-id>`; do not depend on the main checkout being modified by agents.
5. Use explicit run ids for automation. `ai/runs/_active` is only a convenience pointer for interactive use.
6. Mobile/UI verification that is classified as required must complete Appium evidence and runtime attestation for the exact tested build before final verification passes.
7. Workflow outputs for machine-gated stages now include validated JSON sidecars in addition to Markdown.
8. GitHub integration can publish `agentic-workflow-verification` for the exact run commit; configure repository rules to require that status together with `validate`.

Compatibility metadata is independent of runtime SemVer:

- workflow format: `1`
- artifact schema format: `1`

A future runtime release can therefore be 1.x or 2.x without necessarily changing serialized workflow/artifact formats. When a format version changes incompatibly, its migration notes will state the required conversion separately.
