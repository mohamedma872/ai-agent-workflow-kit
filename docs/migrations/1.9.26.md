# 1.9.26 — Branch impact analysis

Runtime 1.9.26 adds a verified branch impact analysis. Two read-only roles are added to `ai/workflows/feature.yaml` and `ai/subagents/contracts.yaml` (`impact-analysis`, `impact-verification`); they are not scheduled by the feature stages, so existing runs are unaffected. Guard rules and artifact schemas are unchanged.

## What changes for you

- **New command `/impact`** (`.claude/commands/impact.md`): baseline, specialist fan-out, six sweeps, adversarial verification, verified register. See [docs/impact-analysis.md](../impact-analysis.md).
- **New CLI commands:**
  - `agentic impact <run-id> --base <ref> --head <ref> [--prod <ref>]` — deterministic baseline and read-only worktrees.
  - `agentic impact-report <run-id>` — register in Markdown, CSV (Excel) and JSON.
- **New specialists:** `impact-analyst` (finds head-only behavior changes for one scope) and `impact-verifier` (tries to refute one finding through one lens).
- **`behavior-regression-reviewer`** now also checks nullable-default changes, broadcasts without listeners, missing route names, literal find-and-replace slips, dropped base fixes, shared-client timeouts/interceptors, and split storage. It must check the production branch and the shipping path before reporting.

## Action required

None. If you copied `behavior-regression-reviewer.md` into a project and edited it, merge the new checklist items by hand. Copy `impact-analyst.md`, `impact-verifier.md` and `commands/impact.md` into projects that use their own `.claude/` folder.

## Evals

Six new cases in `ai/tasks/subagent/cases.yaml`:

| Case | Role | Expects |
|---|---|---|
| `regression-nullable-default` | behavior-regression-review | high: no-3DS path lost |
| `regression-listener-removed` | behavior-regression-review | medium: broadcast without listener |
| `regression-clean-rename` | behavior-regression-review | no high finding |
| `impact-analyst-nullable-default` | impact-analysis | high: no-3DS path lost |
| `impact-verifier-refutes-production-same` | impact-verification | no high finding (production already has it) |
| `impact-verifier-keeps-true-regression` | impact-verification | high: expired-session logout skipped |

Run them from a plain terminal (live Claude evals refuse to run inside a Claude Code session):

```bash
node ai/evals/run.js subagent run --case impact-verifier-refutes-production-same --agent claude
```
