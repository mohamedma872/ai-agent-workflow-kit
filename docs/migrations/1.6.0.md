# Migration to 1.6.0

Runtime 1.6.0 fixes three places where `agentic doctor` reported a missing tool that was actually installed. No workflow, artifact or state format changes.

## What was wrong

```text
! ios:simulator      optional missing       could not enumerate simulators
✗ appium:node        required incompatible  current Node 20.19.4; appium-mcp requires Node 22+
! frontend:build-script optional missing    no frontend build script detected
```

- **iOS**: with `xcode-select` pointing at `/Library/Developer/CommandLineTools`, `xcrun simctl` fails even when Xcode is installed (for example at `~/Desktop/Xcode.app`). `ios:xcodebuild` also passed even though `xcodebuild` could not run.
- **Appium Node**: the check read the Node version of the doctor process (the Node that `agentic` is linked under), not the Node that would run `appium-mcp`. It gave no route to a Node 22+ that was installed but not the default.
- **Frontend**: every React Native app was classified as a web frontend because it depends on `react`.

## After upgrading

```bash
agentic update
cd <your-mobile-project>
agentic init      # switches a standard `npx appium-mcp` entry to `agentic mcp appium`
agentic doctor
```

`agentic init` only rewrites the standard `npx -y appium-mcp…` form, and keeps `env`, `timeout`, a pinned version and extra arguments. Custom Appium commands are left unchanged. To pin a specific Node for Appium, set `AGENTIC_APPIUM_NODE` to a Node 22+ binary or bin directory.

## Optional: fix Xcode system-wide

`agentic` runs work without this, but Xcode tools you run outside `agentic` (`react-native run-ios`, `xcodebuild` in your shell) still need it:

```bash
sudo xcode-select -s /path/to/Xcode.app/Contents/Developer
```

The doctor prints the exact path.

## If Appium MCP crashes with ERR_MODULE_NOT_FOUND 'appium'

An npx cache created under `legacy-peer-deps=true` is missing the `appium` peer. The 1.6.0 launcher disables that setting for Appium MCP, but a cache created earlier must be removed once:

```bash
grep -l appium-mcp ~/.npm/_npx/*/package.json   # locate the cache directory
rm -rf ~/.npm/_npx/<that-directory>
```
