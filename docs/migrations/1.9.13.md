# Migration to 1.9.13

No action required. One capability rule became more precise; nothing else changed.

## Checkpoint names no longer block the capture command

Device evidence could fail with no screenshots at all when a checkpoint name happened to contain a verb:

```text
[ai-guard] subagent capability: role "mobile-evidence" may not run mutating shell commands
  node .../mobile-evidence.js capture RUN --platform android --name 01-fresh-install-login
```

A mutating verb is now only recognised in command position. If a run was blocked this way, resume it:

```bash
agentic resume <run-id>
```

Note that a blocked evidence attempt is not reachable through `agentic retry`, because it is recorded under `state.evidence` rather than as a phase; `agentic resume` re-runs it.

## Still denied

```bash
rm -rf lib                    # verb in command position
ls && rm -rf build            # in any pipeline segment
cat a | tee lib/main.dart
npm install left-pad          # package install names its manager
git commit -m x               # history rewrite
echo x > lib/main.dart        # redirect
```
