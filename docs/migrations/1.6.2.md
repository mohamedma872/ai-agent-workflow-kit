# Migration to 1.6.2

No action required.

Runtime 1.6.2 stops React Native apps from being routed to web frontend specialists. Before this fix, every `/feature` run in a React Native repository ran the web `frontend` analyst, and every `.ts`/`.tsx` change ran `frontend-review` alongside `react-native-review`. Both were extra agent runs aimed at the wrong platform.

| Repository | Before | After |
|---|---|---|
| React Native app | react-native, frontend · react-native-review, frontend-review | react-native · react-native-review |
| React Native app with `web/`, `frontend/` or `apps/web/` | frontend | frontend (unchanged) |
| React / Next / Vue / Angular web app | frontend · frontend-review | unchanged |

Runs already in progress keep their recorded role selection. New runs and resumed stages use the corrected routing.
