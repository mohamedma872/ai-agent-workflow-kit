# 1.9.29 — Real cost in subagent evals, and the budget reaches the run

Runtime 1.9.29 changes `ai/workflow/router.js` (a new optional flag) and the subagent eval adapter. The workflow, roles, guard rules and artifact schemas are unchanged.

## What changes for you

- **Cost is filled in.** Subagent eval rows now carry `cost_usd` and `models` as Claude reports them. Before, they were always `$–`. Each run folder also gets `executor-meta.json` with the full token usage.
- **`--budget` is enforced.** Before this release, the adapter didn't pass `--budget` to the router, so each subagent run was capped at the router default of $20. Runs now use the budget you give, or the task default of $3.
- **New router flag.** `router.js exec … --meta-file FILE` is available to any caller that wants the executor's cost and usage. Without the flag, nothing changes.

## Action required

None. Earlier subagent rows keep `cost_usd: null`. Don't read those as zero cost.

## Check

```bash
node ai/workflow/router.js --selftest
node ai/evals/run.js subagent run --case security-token-logged --agent claude --budget 2
```
