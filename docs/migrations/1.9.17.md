# Migration to 1.9.17

This release reverts 1.9.16. No action is required unless you turned spec publishing on.

## If you enabled `specs:`

Remove the block from `.agentic/config.yaml`:

```yaml
specs:
  enabled: true
  dir: specs
```

Leaving it in place is harmless — nothing reads it any more — but it no longer does anything.

## Specs already published

A `specs/` directory written by 1.9.16 is ordinary committed content. This release does not touch it. Delete it if you do not want it:

```bash
git rm -r specs/
```

## What went away

`agentic spec list` and `agentic spec publish` no longer exist, runs no longer publish their requirements, acceptance criteria and definition of done, and roles no longer receive published specs as context. Run artifacts remain in `.agentic-runs/`, gitignored, exactly as before 1.9.16.
