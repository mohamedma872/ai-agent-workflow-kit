# 1.9.35 — The plan gate follows the agent's own run

`ai/tasks/feature/guard.js` now gates an engine-launched role on its own run (`FEATURE_RUN_ID`) instead of the active run. Interactive sessions still use the active run.

## What changes for you

Running several features at once no longer blocks an approved run's agents because another, unapproved run is the active one. You no longer need `agentic switch <id>` as a workaround.

## Action required

None.
