# Migration to 1.7.0

No action required. Runtime 1.7.0 only adds progress tooling; workflow, artifact and state formats are unchanged.

## One behaviour change

`agentic progress` with no run id used to fail:

```text
✗ progress requires a run id
```

It now opens the terminal dashboard, focused on the active feature. Everything explicit is unchanged:

```bash
agentic progress FEAT-001            # single run, as before
agentic progress FEAT-001 --watch    # as before
agentic progress FEAT-001 --json     # as before
```

Scripts that captured `agentic progress` output are safe: without a TTY the dashboard prints one frame and exits rather than taking over the terminal. For machine-readable output prefer `agentic runs --json` or `agentic progress <id> --json`.

## New commands

```bash
agentic dashboard [--all] [--run <id>]   # the GUI
agentic runs [--all] [--json]            # list features, ▸ marks the active run
agentic switch <run-id>                  # make a feature the active run
```

See [docs/progress-dashboard.md](../progress-dashboard.md).
