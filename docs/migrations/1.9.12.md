# Migration to 1.9.12

No action required. No state, artifact or configuration format changes.

## A status line before the artifact no longer fails the stage

Agents often prefix a sentence before the JSON they were asked to return. That used to be fatal:

```text
✗ review output is not valid JSON: Unexpected token 'S', "Still work"... is not valid JSON
```

The first balanced JSON value is now extracted instead. If a stage failed this way, retry it:

```bash
agentic retry <run-id> <stage>
```

## Reviewers no longer block on evidence that comes later

Review roles are told that device builds and screenshots are produced by `mobile-evidence` after the review stage, and re-checked at final verification. If a run stalled with a reviewer demanding an iOS or Android build, retry the reviews.

If you maintain your own review prompts, add the same note; the gate itself is unchanged, so `mobile-evidence` and verification still require the evidence.
