# Migration to 1.2.0

Runtime 1.2.0 is backward compatible for normal feature workflows and local behavior-preserving refactors.

## New whole-app refactor flow

Use:

```bash
npm run refactor:app -- APP-RF-001 \
  --request "Refactor the entire application without changing behavior" \
  --scope mobile
```

Whole-app runs now stop at a new architecture human gate after architecture assessment/options are generated.

Select one generated option:

```bash
npm run refactor:architecture -- APP-RF-001 A
```

The runtime then produces the selected target architecture, C4 model, Structurizr DSL, and migration waves before stopping at the existing implementation-plan approval gate.

Approve the implementation/migration plan as before:

```bash
npm run refactor:approve -- APP-RF-001
```

## Architecture as code

After the architecture package is complete, the runtime promotes selected artifacts into the product worktree under:

```text
docs/architecture/
```

This includes the target architecture contract, C4 model, `workspace.dsl`, migration plan, and decision evidence.

## Local refactors

Existing local refactors continue to use:

```bash
npm run refactor -- RF-001 --request "Refactor ..." --scope mobile
npm run refactor:approve -- RF-001
npm run refactor:report -- RF-001
```

They automatically skip whole-app architecture stages.
