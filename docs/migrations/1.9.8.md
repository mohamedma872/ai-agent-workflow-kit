# Migration to 1.9.8

No action required. No state, artifact or configuration format changes.

## A recorded coverage waiver now actually unblocks a refactor

This sequence used to leave the run stuck forever:

```bash
node ai/workflow/refactor-coverage.js waive REF-001 B-3 --reason "accepted risk" --owner "Name"
agentic retry REF-001
# -> still: characterization coverage blocked: B-3: high behavior is uncovered
```

An uncovered critical/high behavior now clears when a waiver with both a reason and an owner is recorded for it. A waiver missing either field, or recorded against a different behavior id, still blocks.

## behavior-equivalence no longer fails on wording

Contract entries are compared on identity rather than on the sentence around them, and the order of identity sequences is now checked, so a reordering such as `validate -> charge` becoming `charge -> validate` blocks where it previously passed. If you kept a run blocked only by wording differences, retry the stage:

```bash
agentic retry <run-id> behavior-equivalence
```

The gate still compares free text produced by two different agents. If it blocks on entries that are plainly the same contract described differently, record the difference as an approved `intentionalExceptions` entry in the refactor invariants rather than weakening the gate.

## mobile-evidence honours its declared retry policy

A timed-out device run now takes the second attempt its workflow entry already declared, instead of stopping at the first timeout. Each attempt is independent: screenshots and the attestation are measured from that attempt, so evidence from an earlier one is never accepted.

## Paths in messages match your project

Messages and recorded state now say `.agentic-runs/<id>/...` for a project you ran `agentic init` in, and keep `ai/runs/<id>/...` only inside the runtime repo itself.
