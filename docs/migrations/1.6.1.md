# Migration to 1.6.1

No action required. Runtime 1.6.1 corrects the optional `ios:xcode-select` doctor warning added in 1.6.0:

- Under `agentic doctor` the warning did not appear, because the CLI had already injected `DEVELOPER_DIR` for its runs.
- The path it reported came from `xcode-select -p`, which returns `DEVELOPER_DIR` whenever that variable is set.

After `agentic update`, `agentic doctor` reports the real system selection and the exact fix:

```bash
sudo xcode-select -s /path/to/Xcode.app/Contents/Developer
```

A `DEVELOPER_DIR` you export yourself is treated as your choice, so no warning is shown.

See [1.6.0](1.6.0.md) for the Xcode, Appium Node 22+ and React Native stack-detection fixes.
