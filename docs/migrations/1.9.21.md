# 1.9.21 — Single engineering rulebook

Runtime 1.9.21 consolidates the engineering rules into one canonical file:

```text
ai/standards/engineering-rulebook.md
```

It now contains the complete rule set for:

- Clean Code and readability
- SOLID
- Clean Architecture and dependency direction
- feature boundaries and composition
- data/state ownership
- concurrency, retries, debounce, and idempotency
- error handling
- Fowler-style refactoring and code smells
- simplicity and over-engineering
- testing
- security/privacy
- observability
- performance
- navigation
- e-commerce architecture
- the 13 mandatory architecture coverage groups
- finding structure
- severity and priority
- architecture report semantics
- ADR rules
- architecture fitness functions
- architecture Definition of Done
- rule-conflict precedence

The workflow roles now reference `engineering-rulebook` instead of the older `clean-engineering` standard.

`ai/standards/clean-engineering.md` remains only as a compatibility pointer. It is not a second source of truth.

Supporting architecture-report documentation links to the rulebook instead of duplicating its rules.

No project configuration changes are required.
