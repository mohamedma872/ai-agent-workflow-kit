# Migration to 1.5.3

Runtime 1.5.3 fixes the remaining macOS external-project self-test failure seen after upgrading to 1.5.2.

## What failed

On macOS, the same temporary directory can be represented as both:

```text
/var/...
/private/var/...
```

The external-project self-test created a worktree correctly, but then checked it with a raw string-prefix assertion:

```text
assert(wt.path.startsWith(path.join(project, '.ai-worktrees')))
```

That assertion could fail even when both paths pointed to the same physical directory.

## Fix

Runtime 1.5.3:

- compares canonical physical paths;
- verifies worktree containment with `path.relative` instead of raw string prefixes;
- compares canonical source-repository paths;
- explicitly runs the external-project isolation test through a symlinked project path.

## Recovery

If 1.5.2 rolled back to 1.5.1 after the external-project self-test failure, run:

```bash
agentic update
```

After 1.5.3 is fetched, the fixed self-tests run before the update is accepted.
