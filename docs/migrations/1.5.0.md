# Migration to 1.5.0

Runtime 1.5.0 adds the safe self-update flow for the current Git-clone + `npm link` installation model.

## Existing users on 1.4.1 or older

Older runtimes do not contain the updater yet, so bootstrap once:

```bash
cd /path/to/ai-agent-workflow-kit
git pull --ff-only
npm ci
npm link
```

After that:

```bash
agentic update --check
agentic update
```

## Safety behavior

`agentic update` operates only on the installed runtime clone.

It refuses to continue when:

- the runtime working tree has tracked or untracked local changes;
- the runtime is on a custom/contributor branch;
- local `main` cannot fast-forward to `origin/main`;
- the remote runtime metadata is not a stable SemVer release.

After moving to the new runtime commit it runs:

```text
npm ci
npm link
runtime version verification
standalone CLI self-test
external-project isolation self-test
```

If post-update installation or verification fails, the updater restores the exact previous runtime Git commit and attempts to restore dependencies/linking.

The user's target project, its source files, `.agentic-runs/`, and `.ai-worktrees/` are not touched by the updater.

## Check-only mode

```bash
agentic update --check
```

Machine-readable status:

```bash
agentic update --check --json
```

The check performs a Git fetch but does not modify the runtime working tree.
