# Migration to 1.5.1

Runtime 1.5.1 fixes the executable permission of the standalone `agentic` entrypoint on macOS/Linux.

## Existing clone + npm link installations

If `agentic version` currently returns:

```text
zsh: permission denied: agentic
```

bootstrap once from the runtime clone:

```bash
chmod +x ai/cli/agentic.js
git config core.fileMode false
git pull --ff-only
npm ci
npm link
```

Then verify:

```bash
agentic version
```

The repository now tracks `ai/cli/agentic.js` as executable and CI rejects regressions.
