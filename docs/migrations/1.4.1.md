# Migration to 1.4.1

Runtime 1.4.1 fixes Appium MCP discovery for standalone mobile projects.

## Existing mobile projects

Rerun initialization from the project root:

```bash
agentic init
agentic doctor --scope mobile
```

Initialization is idempotent. It preserves existing MCP servers and adds the standard Appium MCP entry only when no Appium alias is already configured.

Accepted Appium server names:

```text
appium
appium-mcp
mcp-appium
```

The doctor also checks user-level Claude and Codex MCP configuration. A globally installed `appium-mcp` package is reported separately from an MCP server that is actually configured for an agent client.

For mobile verification, Appium MCP requires Node.js 22 or newer. The core runtime still supports Node.js 20+ for non-Appium workflows.
